## ✨ Features

- **Fully Responsive Design:** Optimized for Desktop, Tablet, and Mobile screens.
- **Modern UI/UX:** Dark/light theme sections with premium typography and hover effects.
- **Interactive Tabs:** Smooth tab switching for Services (Web Dev, Video Editing, Graphics).
- **Mobile Navigation:** Fully functional hamburger menu for mobile devices.
- **Contact Form:** Built-in form validation with mailto integration.
- **Smooth Scrolling:** Seamless navigation between sections.
- **Dynamic Animations:** Floating hero card and glowing effects.

## 🛠️ Technologies Used

- **HTML5** — Semantic markup.
- **CSS3** — Custom styling, keyframe animations, and media queries.
- **Vanilla JavaScript** — DOM manipulation, logic, and interactivity (No frameworks).
- **Tailwind CSS (CDN)** — Rapid utility-first styling.
- **Font Awesome (CDN)** — Premium icons.
- **Google Fonts** — Inter typeface for clean typography.

## 💻 How to Run Locally

You don't need any complex build tools or servers to run this project.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Yash-coder53/cliptab-website.git
   ```
2. **Navigate to the folder:**
   ```bash
   cd cliptab-website
   ```
3. **Run the site:**
   Just double-click on the `index.html` file to open it in your default web browser.
